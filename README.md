I build tools I use myself. Three to start with:

- [farmfind](https://github.com/tigran-martirosian/farmfind): compares farm web shops and works out the cheapest cart for a shopping list.
- [cited-research-assistant](https://github.com/tigran-martirosian/cited-research-assistant): answers questions from a document library and cites the exact passage for every statement.
- [ai-coding-setup](https://github.com/tigran-martirosian/ai-coding-setup): checks an AI coding agent's answer against the log of what it actually ran, and reports what each session costs.
